# 2048 SuperHeels

A fan-made shoe-shelf edition of the 2048 sliding-tile puzzle. Eleven pairs, from a blue ballet flat at 2 to a rainbow platform mule at 2048.

Una edición de zapatero: once pares, de la bailarina azul en el 2 a la mula de plataforma arcoíris en el 2048.

**Play:** [English](https://tile2048.github.io/2048-SUPERHEELS/) · [Español](https://tile2048.github.io/2048-SUPERHEELS/es/)

| Value | Tile |

| 32 | leopard-print pump |

| 128 | polka-dot pump |
| 256 | blue strappy sandal |
| 512 | green glitter lace-up |
| 1024 | houndstooth platform heel |
| 2048 | rainbow platform mule |

## How to play

Arrow keys move the whole board; a swipe does the same on a phone. Two tiles of the same value merge into the next one on the ladder, and the value of the new tile is added to your score. The run ends when the board is full and no two neighbours match, so leave a corner free and plan one merge ahead.
